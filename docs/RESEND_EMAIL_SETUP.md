## Current automated email flows

All current automated emails originate in Supabase Auth: organizer signup
confirmation, confirmation resend, password recovery, and voter email OTP.
Configure Resend as Supabase's custom SMTP provider to deliver them through
Resend. Supabase continues generating and validating the auth links and codes;
the Next.js app does not need an email SDK or a Resend API key for these flows.

Organization team invitations currently return a link for an organizer to share.
They do not send email. In-app notifications and Paystack's own receipts are not
emails generated by this app. Additional application email flows would need a
server-only Resend integration when implemented.

## Hosted Supabase configuration

Project: `jjgwyvxntzrjugauknzo`.

Open Authentication → Email under Notifications → SMTP Settings. Enable custom
SMTP and save:

| Setting | Value |
| --- | --- |
| Sender email | `info@votecasthub.com` |
| Sender name | `VotecastHub` |
| SMTP host | `smtp.resend.com` |
| SMTP port | `465` |
| SMTP username | `resend` |
| SMTP password | A Resend API key authorized to send for `votecasthub.com` |

Create the key in Resend and paste it directly into Supabase's SMTP password
field. Never share it in chat or put it in a `NEXT_PUBLIC_` variable. No Vercel
email environment variable is needed for Supabase SMTP delivery.

Set Supabase's Site URL to `https://votecasthub.com`, allow the auth callback URLs
used by the app, and set Vercel's production `NEXT_PUBLIC_SITE_URL` to that origin.
Redeploy if changing that public environment variable. Keep email confirmation
and Turnstile CAPTCHA enabled. Review hosted email rate limits for intended use.

## Cloudflare routing and Resend DNS

Cloudflare Email Routing receives incoming mail for `info@votecasthub.com` and
`support@votecasthub.com`. Resend sends outbound mail. Keep Cloudflare's root MX
records and use the exact sending records shown by Resend, including the MX/SPF
records at its return-path subdomain and its DKIM records. Do not enable Resend
receiving at the root domain while Cloudflare handles that domain's incoming mail.

Keep click tracking disabled for authentication emails so verification links are
not rewritten. Configure auth email templates in Supabase, including the email
OTP template used by voters; preserve the existing confirmation/recovery URLs and
the OTP template's `{{ .Token }}` code.
